# Cardinal Store: GitHub Pages Demo Site

A small example website for a fictional dumpling shop, built with **GitHub Pages and Jekyll** as a teaching demo for publishing a static site from a GitHub repository.

Live: **[shengqin.github.io/cardinalstore](https://shengqin.github.io/cardinalstore/)**

## Step-by-step screenshots (`img/`)
1. `1newrepo.png`: create a new repository
2. `2reponame.png`: name it
3. `3create_index_html.png`: add `index.html`
4. `4pages.png`: turn on GitHub Pages
5. `5addviaupload.png`: upload images
6. `6dev.png`: preview the deployed site
7. `7yaml.png`: set the Jekyll theme in `_config.yml`

**Stack:** HTML, Jekyll (`_config.yml`), SCSS (`assets/css/style.scss`)
